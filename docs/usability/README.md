Only the compact before-and-after set is in git: `compare/` (20 side-by-side JPEGs of the main screens, phone and laptop, under 1 MB in all; `compare/README.md` shows them in order).

The raw screenshots are kept out of git (they are about 30 MB) and live on the owner's computer:

| Set | Where | What |
|---|---|---|
| Round 1 audit, "before" | `~/Projects/northvale-learn/docs/usability/` (the owner's checkout, untracked) | 329 numbered PNGs: 001–185 phone, 186–329 laptop |
| After Round 1 fixes | this folder: `after/`, `after2/` (untracked) | Each fix, named by audit item (a01…h21, p01…) |
| Round 2 audit | this folder: `round2/` (untracked) | r01…r41, phone in Spanish and the Navy look, laptop in English |

To make the compare set again: take fresh "after" shots of the same screens, then put each next to its "before" (the scripts used are described in `docs/USABILITY-AUDIT.md`).
